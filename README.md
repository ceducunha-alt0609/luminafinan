# Lumina Finance PWA

App PWA de controle financeiro pessoal usando HTML, CSS e JavaScript Vanilla + Tailwind CDN.

## Arquivos
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icons/

## Instalação
Suba todos os arquivos para a mesma pasta no GitHub Pages ou servidor HTTPS.
Abra o app no Chrome/Edge mobile/desktop e use o botão Instalar.

## Observações
O app usa localStorage para persistência local.
O Service Worker faz Cache First com fallback para index.html em navegação offline.
